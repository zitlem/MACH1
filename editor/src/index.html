Folder
Click a program or a found line to open it. Tools are checked against the folder's machine memory (m8ysram) or TOOLDATA file when it has one.
Compare
Changes from the other program to this one. Records are matched on their contents, so inserted or deleted units do not shift the rest. Click a change to go to it.
Tools
A tool is found when the tool data has the same type, nominal size and suffix (and part, for turning tools). Open a machine's m8ysram or a TOOLDATA file to check against it. Click a tool to go to it.

Keys

Soft keys (bottom row)

Like the control's: ◀ ▶ page through a menu and ◀ on its first page goes back up. A key with ▲ opens another menu. PROGRAM EDIT turns editing on (Ctrl+E); PROGRAM COMPLETE turns it off. While editing, on a field with choices (PTN, a tool, a direction ...) the keys are the choices (Alt+1 ... Alt+0); ◀ brings the menu back.

TOOL PATH the plot · MACHIN. TIME where the time goes · PROGRAM LAYOUT the run order and priority numbers · PROGRAM FILE the opened folder's programs · WORK No. another open program · SEARCH a unit by number or name.
