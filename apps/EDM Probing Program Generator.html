About this drawing
The machine zero is the wire at the left-rear end of travel: machine X runs 0 to + the travel, Y 0 to − the travel, as G53 moves do. The M8 holes are drawn Ø8; the counterbored holes that fix the table down are left out. Check a hole or two on the machine before you rely on the drawing. The DXF is AutoCAD R12, which every CAD program opens.
